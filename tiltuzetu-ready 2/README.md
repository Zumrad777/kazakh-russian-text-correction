# TilTüzету

**TilTüzету** is a web-based application designed to correct spelling mistakes in mixed Kazakh-Russian text and translate text into Kazakh or English.

## Features

- **Spelling Correction** — detects selected spelling mistakes and provides rule-based correction suggestions.
- **Text Translation** — translates text using the MyMemory Translation API.
- **Language Selection** — supports Kazakh, Russian, and English.
- **REST API** — provides endpoints for text correction, translation, and application status.
- **MongoDB Integration** — optionally stores correction and translation history using MongoDB Atlas.

## Technologies

- Python
- FastAPI
- HTML, CSS, JavaScript
- MyMemory Translation API
- MongoDB Atlas (optional)

## Project Status

TilTüzету is a prototype MVP demonstrating the workflow of spelling correction and text translation for Kazakh-Russian mixed-language text.

Spelling correction currently uses a basic rule-based approach. Translation depends on an external API and may be subject to availability and usage limits.
